# Ezer

A static site for Ezer, a full-service social studio. Open `index.html`, or run a local server from this folder:

```
python -m http.server 4321
```

Then visit http://localhost:4321

## Before you publish

- Replace the sample projects on the home and work pages with real work.
- Replace the client notes on the home page with real clients.
- Update `hello@ezer.studio`, the WhatsApp number in `contact.html`, and the social links in the footer.
- Prices are starting points. Edit them on the home page and in `services.html`.
